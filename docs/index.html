    Publishing to GitHub Pages

    1. Commit these files and push them to your GitHub repository.
    2. Enable GitHub Pages and select the docs/ folder as the site source.
    3. Share the GitHub Pages URL so anyone can open the chat, provide their own token, and help the learner grow.
